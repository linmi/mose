# Mose

A native macOS app for Logitech MX mice — and other mice too: button remapping, gestures, smooth scrolling, per-app profiles, battery and Easy-Switch, from the menu bar.

**Download:** grab the latest `Mose-<version>.dmg` from [Releases](https://github.com/linmi/mose/releases). Mose updates itself after that (Settings → Updates).

Requires macOS 15 or later.
